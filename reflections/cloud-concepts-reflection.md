Cloud computing is an important part of my daily life because it helps me study, communicate, and manage my files more easily. The cloud services I use most are Google Drive, Canva, and Messenger. Google Drive allows me to store and access my files from any device, Canva helps me create school projects online, and Messenger keeps me connected with my classmates and teachers. These applications are examples of Software as a Service (SaaS) because they provide software over the internet without requiring users to install or maintain it. They also use the Public Cloud deployment model since they are available to anyone with an internet connection. I also learned that Git and GitHub are valuable tools for cloud-based projects. Git tracks changes made to files, while GitHub allows teams to collaborate, review updates, and manage projects efficiently. Overall, this lesson helped me understand how cloud computing supports the applications I use every day and why version control is essential for teamwork and developing reliable cloud solutions.
